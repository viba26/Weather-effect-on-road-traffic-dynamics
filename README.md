# Weather-effect-on-road-traffic-dynamics
This project investigates the effects of rainy and snowy weather conditions on urban traffic flow and vehicle dynamics using Python and SUMO.

The simulations are based on the LuSTScenario urban mobility scenario, which provides the traffic network and scenario data.

Original scenario: https://github.com/lcodeca/LuSTScenario

Main File

simulation.py – Python script for running the traffic simulation.

Objectives

Simulate traffic under different weather conditions.

Compare traffic flow and vehicle behavior in dry, rainy, and snowy conditions.

Analyze changes in average travel time, traffic flow, and CO₂ emissions.
